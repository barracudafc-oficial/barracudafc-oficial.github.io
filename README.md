# Página web oficial — Club Profesional Barracuda F.C.

Sitio estático de Barracuda F.C. para GitHub Pages.

## Publicación
1. Subir `index.html`, `styles.css`, `script.js`, `assets/` y `CNAME` a la raíz del repositorio `barracudafc-oficial.github.io` (no subir el ZIP directamente).
2. En GitHub, ir a **Configuración → Páginas** y elegir **Implementar desde una rama**, rama `main`, carpeta `/ (raíz)`.
3. Esperar la publicación en `https://barracudafc-oficial.github.io`.
4. En Namecheap BasicDNS, eliminar la redirección anterior del dominio raíz a `http://www.barracudafc.com/` y configurar los registros DNS que indique GitHub Pages. Para el dominio raíz, los A records de GitHub Pages son: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Para `www`, usar CNAME `barracudafc-oficial.github.io`.
5. En Configuración → Páginas confirmar `barracudafc.com` como dominio personalizado y, una vez emitido el certificado, activar **Forzar HTTPS**.
6. Mantener intactos los registros MX/TXT del correo cuando se configure el buzón de Presidencia.
